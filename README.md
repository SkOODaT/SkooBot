# SkooBot

Pokemon and PKHeX.Core.dll.

## Setup

Requires Python 3.13.13+

```
# Install Requirements.
pip install -r requirements.txt 
```

## Run

**pkFileChecker.py**
- Currently supports all Gen 7/8/9.
- Place pokemon files into same directoty and run `python pkFileChecker.py`.
- Alternatively specifiy a specific file run `python pkFileChecker.py pokemon.pk9`.
